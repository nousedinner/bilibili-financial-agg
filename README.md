# B 站财经聚合

面向个人使用的 B 站财经视频聚合服务和 Android APP。关注博主后，后端定时采集视频、评论和弹幕，优先使用字幕，必要时通过 MiMo ASR 转写，再生成摘要和日报。后端当前版本为 1.1.5，兼容现有 1.1.3 APP。

## 部署入口

- [服务器部署与维护](docs/DEPLOYMENT.md)：环境配置、数据库升级、启动、备份和故障检查。
- [Android 构建与使用](docs/ANDROID.md)：安装、连接 KEY、B 站重新授权和通知。
- 接口定义由服务提供：`/docs`、`/openapi.json`，业务请求携带 `X-API-Key`。

仓库仅保留应用源码、构建和部署文件及使用文档。历史审查、验证记录、源码备份、测试材料和样例数据已移出当前目录树，旧版本仍可从 Git 历史恢复。

```text
src/                       后端源码
scripts/manage_db.py        数据库迁移与连接 KEY 生成
android/                   Android 源码及 Gradle 构建文件
config/                    配置模板
Dockerfile                 后端镜像
docker-compose.yml         服务启动配置
requirements.txt           后端依赖
docs/                      部署和 APP 使用说明
```

## 运行方式

后端使用 FastAPI、MySQL 和 Docker，复用 `mysql-net` 中的 MySQL 容器；APP 使用 Kotlin / Jetpack Compose。一个服务实例、一个 Uvicorn worker 即可，不需要额外队列服务。

复制 `config/config.example.yaml` 为 `config/config.yaml`，复制 `config/.env.example` 为根目录 `.env` 并填写真实配置，然后按部署指南执行数据库迁移、首次生成连接 KEY 和启动服务。真实配置、数据库、B 站会话、签名文件及安装包不入 Git，也不进入 Docker 构建上下文。

## 任务与授权边界

自动采集默认只接纳最近 7 天的新视频，所有入口保留 2026-07-01 的绝对下限。升级、重启、重新授权和更换模型不会触发历史视频批量入队；历史补抓必须明确指定范围和额度。只有完整发现扫描才能推进覆盖水位。

字幕、ASR 片段、分析结果分别保存检查点，只有完整转写才能发布正式摘要；评论和弹幕分别记录结果。超过 60 分钟的视频跳过 ASR，模型调用受预算限制。

1.1.4 修复了模型漏字段被补为中性、任务异常后的锁与状态收尾、下载取消清理及字幕降级；无评论或弹幕样本时返回无样本状态，不生成情绪比例。连接 KEY 改为摘要存储，原有手机 KEY 继续有效，升级前需执行结构版本 8 的迁移。

1.1.5 保留付费分析阶段跨输入版本的三次尝试上限，并每分钟补写尚未提交的任务终态。旧版无校验来源且为 100% 中性的互动比例暂标为 `unverified`，接口不展示该比例，原记录保留，不自动批量重算。结构版本仍为 8。

APP 和服务器统一使用连接配置中的 KEY。B 站授权是服务器独立保存的会话，需通过官方 APP 扫码确认更新。服务器每 30 分钟检查授权，网络异常和风控不会误报为授权过期；APP 默认通过启动检查和约 15 分钟的后台周期检查展示系统通知，实际时间受手机系统调度影响。
