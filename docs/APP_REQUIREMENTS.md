# 财经聚合Android APP 需求文档

## 概述
轻量级Android客户端，消费财经聚合API，为用户提供B站财经UP主内容的AI分析结果。

技术栈：Kotlin + Jetpack Compose + Material 3
最低API：26 (Android 8.0)
目标API：34 (Android 14)

---

## 认证方式

数据库用户名+密码认证。密码由服务端生成（长随机串），客户端首次使用时通过bootstrap获取或手动输入。

- 请求时在Header中携带：`X-API-Key: <密码>`
- 所有接口（除health和bootstrap）均需认证
- APP首次启动需配置密码

---

## 页面结构

### 0. 首次启动 — 密码配置
APP首次打开时显示：

- 输入框：API地址（默认已填好 `https://home.cancanneed.top/fin-api/`）
- 输入框：密码（即X-API-Key的值）
- 保存按钮
- 如无密码，可点"创建用户"调bootstrap获取

后续启动自动跳过此页。

### 1. 首页 — Feed时间线
**核心页面，打开APP直接看到**

- 顶部：标题"财经聚合" + 设置图标
- 列表：卡片式展示，每张卡片包含：
  - 博主名称 + 发布时间
  - 视频标题
  - AI摘要（2-3行，可展开）
  - 情绪标签：🟢看多 / 🔴看空 / ⚪中性
  - 情绪分数条（可视化）
- 下拉刷新
- 上拉加载更多
- 点击卡片 → 进入视频详情页
- 右上角筛选：按博主/按情绪过滤

### 2. 视频详情页
**点击某个视频后进入**

- 视频标题 + 播放量 + 时长
- **AI分析区块**（重点）：
  - 摘要全文
  - 关键观点（列表）
  - 风险提示（红色警告样式）
  - 数据引用（蓝色标注）
  - 标签（Chip样式）
- **评论分析区块**：
  - 情绪分布饼图或进度条
  - 热门评论列表（3-5条）
  - 评论关键词标签
- **弹幕分析区块**：
  - 情绪分布
  - 弹幕关键词
- 底部：跳转B站观看按钮（打开B站APP或浏览器）

### 3. 博主管理页
**底部导航第二项或设置中**

- 博主列表（名称+标签+视频数）
- 添加博主：
  - 输入B站主页链接或mid
  - 填写名称
  - 填写标签（逗号分隔）
  - 确认添加
- 删除博主（左滑删除或长按）

### 4. 每日汇总页
**底部导航第三项**

- 日历选择器或日期列表
- 选中日期后显示：
  - 整体市场情绪
  - 当日关键观点
  - 风险提示

### 5. 设置页
- API地址配置（默认已内置）
- 密码配置
- 手动触发抓取按钮
- 关于/版本

## 交互细节

### 情绪展示
- bullish（看多）：绿色 `#4CAF50`，图标 ▲
- bearish（看空）：红色 `#F44336`，图标 ▼
- neutral（中性）：灰色 `#9E9E9E`，图标 ●

### 数据加载
- 首次打开显示骨架屏（Skeleton）
- 列表加载中显示圆形进度条
- 加载失败显示重试按钮
- 空状态显示引导文案

## API调用映射

| 页面 | 调用接口 |
|------|---------|
| 首页Feed | `GET /api/feed?limit=20` |
| 视频详情 | `GET /api/videos/{bvid}` |
| 博主列表 | `GET /api/bloggers` |
| 添加博主 | `POST /api/bloggers` |
| 删除博主 | `DELETE /api/bloggers/{mid}` |
| 每日汇总 | `GET /api/daily/{date}` |
| 系统状态 | `GET /api/status` |
| 创建用户 | `POST /api/bootstrap` |
| 触发抓取 | `POST /api/fetch/trigger` |

## 不做（明确排除）

- ❌ 视频播放功能（跳转B站）
- ❌ 多用户数据隔离（当前单用户）
- ❌ 推送通知
- ❌ 评论/弹幕原文展示（只展示分析结果）
- ❌ 搜索功能

---

## 验收标准

1. 首次启动能配置密码并保存
2. 能看到Feed列表并下拉刷新
3. 点击视频卡片能看到完整分析
4. 能添加/删除博主
5. 能查看每日汇总
6. 情绪标签颜色正确
7. 无网络时有友好提示
