- 保留 FastAPI / MySQL 单体及单用户配置，动态抓取继续暂停。读取接口密钥与替换服务器授权的管理密钥分离。
- 仅显式登记的 VideoWork 参与调度；历史 NULL、旧失败次数、旧 ASR、模型或提示词变化均不创建任务。所有入口保留 2026-07-01 绝对下限。自动采集默认最近 7 天；缺失水位线只建立当时起点，后续扫描不把起点退回 7 天前。
- 手动批次固化日期、候选名单、额度和来源。重启不扩大候选范围；`incremental / retry / manual_backfill / auth_recovery` 可追溯。授权恢复只选择已登记、明确关联旧凭据、未超出原范围的阻塞任务。
- 发现进度与分析进度分开。完整发现且候选持久化后才推进覆盖水位；412、分页异常、预算截断不推进。同秒发布时间的分页边界继续扫描到闭合，近期窗口跳过的历史缺口单独记录。
- 各阶段独立状态、计次和退避，评论与弹幕分别恢复。网络、风控、明确授权失效、内容不存在、策略跳过各自归类；请求有间隔及冷却。风控不被解释成登录失效，也不立即转为收费 ASR。
- 完整转写先保存私有检查点，ASR 成功片段逐片保存，模型失败后复用。缺片不得发布；超过 60 分钟的 ASR 标记策略跳过。长文按完整内容分段分析，公开转写与正式摘要在同一事务发布，下游失败保留上一对公开结果。
- 独立连接保活 MySQL 命名锁，并以所有者与代次在写入事务内约束提交。每次收费 ASR / LLM 请求前检查所有权，失锁取消在途任务并禁止下一段；已发出的请求无法撤销，仍可能发生一次费用。
- 独立 30 分钟授权检查和 60 秒通知发送，不等用户打开 APP。首次即失效同样创建事件，状态与待发告警同事务保存，去重、退避和最多每日提醒；未知状态保留未解除事件，确认有效后记恢复时间。旧凭据探测结果不得覆盖新版本。
- 新会话在服务器生成、三分钟到期；候选会话在线验证登录和账号后，通过凭据版本 CAS 原子替换受限文件，不把 Cookie 返回 APP，不读取官方 APP 私有目录。管理密钥仅在普通 Android KeyStore 保护的本地文件保存，并绑定 HTTPS 服务器地址。
