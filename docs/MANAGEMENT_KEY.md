# 统一使用连接 KEY（1.1.3 起）

本应用面向单用户，服务器连接、发起 B 站授权和指定任务恢复统一使用连接配置中已有的 KEY，HTTP 请求携带 X-API-Key。已有 KEY 不变，无需再输入、备份或生成第二把管理密钥。

旧版的 X-Management-Key、FIN_AGG_MANAGEMENT_KEY 及 create-management-key 命令已经移除。APP 升级时清理旧管理密钥文件及其 Android KeyStore 条目；服务端不再读取旧管理密钥。旧文件如因回滚而保留在私有备份中，也不参与当前版本鉴权。

统一鉴权后，缺失、错误和停用的连接 KEY 都会在进入业务逻辑前被拒绝。B 站授权仍需要用户在官方 APP 确认，服务器继续校验候选登录状态、账号、会话 nonce、有效期及凭据版本，不把 B 站 Cookie 返回 APP。日常查看授权状态和通知的方式保持不变。

连接 KEY 已具有管理权限，APP 的云备份和设备迁移备份排除了包含它的 DataStore 文件。换手机或重新安装后，按原来的方式配置服务器地址和连接 KEY 即可。
