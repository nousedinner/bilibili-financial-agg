## 审查中修复的恢复边界

1. **缺少环境 UID 时的账号固定。** 之前只在设置 `BILI_UID` 时约束目标账号。现在未配置时使用已保存凭据的账号 ID，避免重新授权误切换采集账号。
2. **文件替换成功而数据库提交失败。** 之前下一次轮询会被版本冲突拒绝。现在只有当前文件与本会话保存的候选完全匹配时，才允许补记完成状态；其他会话候选不能冒领结果。
3. **旧完成结果覆盖新的失效证据。** 之前重复读取已完成会话可能无条件补写 valid。现在已完成结果仅作幂等返回，过期结果不再补写状态；有效期内的补记也不会覆盖同一凭据版本已有的较新检查记录。这些判断在同一所有者事务与授权状态行锁内执行。

测试夹具也统一冻结授权路由时钟，避免把九月的固定测试时间与真实十月时间混用，从而错误依赖过期检查的先后顺序。
