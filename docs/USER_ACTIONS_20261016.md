# 你回来后需要做的操作

目前服务器授权仍无效。之前那次手机扫码确认没有完成后端验证，旧二维码也已经失效。新版本已经补齐回调兼容和失败恢复，需要用新的二维码再确认一次。

## 1. 更新验证 APP

安装相邻 AppB 目录中的 [finapp-v1.1.1-poc.apk](../../AppB/implementation-20261016/finapp-v1.1.1-poc.apk)。名称是“财经聚合验证”，包名 `com.finapp.appb.poc`，可以与原 APP 并存。

直接覆盖更新当前验证包，保留已配置的连接、管理密钥和通知权限。无需卸载，也无需 ROOT。普通安装和扫码不需要连接 ADB。

## 2. 重新确认服务器授权

1. 打开“财经聚合验证”，进入“设置 → 授权与通知”。
2. 点击“重新授权服务器”，滑到下方并点击“保存二维码到相册”。
3. 在官方哔哩哔哩 APP 中打开“扫一扫 → 相册”，选择刚保存的最新二维码，使用服务器采集账号确认。
4. 在约三分钟有效期内返回验证 APP，保持授权页面，等待顶部显示“授权有效”和“服务器授权已验证并更新”。
5. 告诉我实际结果，我再核对服务器凭据版本、告警恢复时间和任务范围。不要只凭官方 APP 的确认页面判断后端成功。

网络或服务临时异常会在同一会话有效期内自动重试；到期后需要生成新二维码。如果应用被系统结束、票据已消费但网络响应丢失，仍可能需要重新扫码。不要重复使用之前保存的旧图片。

## 3. 补齐即时推送配置，再验收熄屏通知

正常通知权限和系统通知点击跳转已经验证。当前还没有 Firebase 项目配置，后台检查补漏不能代替 FCM 实时推送。

先告诉我是否已有 Firebase 项目即可。已有项目时，提供 Android 客户端配置和服务器服务账号文件的本地路径；服务账号私钥不要直接贴进聊天。验证包需要对应 `com.finapp.appb.poc` 的 Android 客户端配置。

配置完成后，再在 APP 点击“发送服务器测试通知”，退到后台并熄屏；真实收到系统通知后点击它，检查“已确认收到过服务器测试推送”。另外需要按你日常使用的网络验证送达。完成前，生产保留有预算上限的 ASR 降级，不改为无人知晓的长期授权等待。
