### 如果后续决定增加 FCM

正常通知权限和系统通知点击跳转已经验证。当前还没有 Firebase 项目配置，后台检查补漏不能代替 FCM 实时推送。

后续决定接入时，再确认是否已有 Firebase 项目。已有项目时，提供 Android 客户端配置和服务器服务账号文件的本地路径；服务账号私钥不要直接贴进聊天。验证包需要对应 `com.finapp.appb.poc` 的 Android 客户端配置。

Firebase 是 Google 的应用服务平台，这里只使用其 Cloud Messaging 手机推送。通知权限负责允许 APP 显示通知；推送通道负责把服务器的消息送到手机。你不需要编写代码或自行配置 VPS。首次接入时，先用自己的 Google 账号登录 [Firebase 控制台](https://console.firebase.google.com/)，停在首页，再按后续指引创建项目。此前没有项目不影响已完成的 B 站授权。

配置完成后，再在 APP 点击“发送服务器测试通知”，退到后台并熄屏；真实收到系统通知后点击它，检查“已确认收到过服务器测试推送”。另外需要按你日常使用的网络验证送达。完成前，生产保留有预算上限的 ASR 降级，不改为无人知晓的长期授权等待。
